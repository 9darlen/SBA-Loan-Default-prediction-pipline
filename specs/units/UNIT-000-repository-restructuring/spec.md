# UNIT-000 - Repository Restructuring

## Intent

Reorganize the existing SBA loan default prediction project into a maintainable Spec-Driven Development repository structure without changing ML behavior.

## Scope

- Classify existing files.
- Move files into responsibility-based folders.
- Fix imports and filesystem paths required by movement.
- Preserve existing model artifact loading.
- Update CI paths.
- Add architecture and Unit documentation.

## Out of Scope

- New model training logic.
- New feature engineering.
- New API.
- New infrastructure.
- New deployment target.
