# Product Vision

## Purpose

This project predicts SBA loan charge-off risk from loan and business attributes.

## Long-Term Goal

Provide a maintainable portfolio-grade ML project that separates training, artifacts, and serving code clearly enough for future AI-assisted development.

## Expected Users

- A learner or portfolio reviewer inspecting the ML workflow.
- A local user running Streamlit to estimate loan default risk.
- A future developer extending the project through Units.

## Current Objective

Preserve the existing model behavior while making the repository easier to understand and maintain.
