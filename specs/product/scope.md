# Scope

## In Scope

- Training an SBA loan default model from the existing dataset.
- Loading existing serialized model artifacts.
- Running a Streamlit prediction UI.
- Running unit tests for feature engineering.
- Maintaining architecture and migration documentation.

## Out of Scope

- New prediction API.
- Database persistence.
- Cloud deployment.
- Dockerization.
- Model registry or MLOps platform.
- New model behavior or feature engineering changes.

## Future Scope

- Model packaging improvements.
- Prediction API.
- Dockerization.
- CI expansion.
- Model lifecycle documentation.
